# Проверка производительности

После `make up && make migrate` создайте приложение и экспортируйте его ID:

```bash
APP_ID=<uuid> COUNT=500 PARALLEL=25 ./scripts/load.sh
```

Критерий ТЗ: API принимает 500 событий без ошибок, p95 приёма остаётся ниже 200 мс на локальной машине, а `hookline_messages_pending` возвращается к нулю после обработки очереди. Результат зависит от CPU, диска и Docker, поэтому измерение выполняется в целевом окружении перед релизом.
